# 性能基准（2026-10-15）

串行、单用户、3 轮 × 8 问 = 24 次完整链路，真实调用硅基流动（embedding/rerank）与 DeepSeek（生成）。
分段口径与线上同一条链路（只调公开函数）。

> ⚠️ **本次未测生成段**（`--skip-llm`）：跑基准时 DeepSeek API 不可达（单发调用 8 分钟无响应）。检索/重排两段数据有效；生成段与端到端数字待 API 恢复后重跑补上。

| 段 | 次数 | 均值 | P50 | P95 | 最大 |
|---|---|---|---|---|---|
| 检索（向量化+双路召回+融合+取正文） | 24 | 161ms | 96ms | 578ms | 1154ms |
| 重排（reranker） | 24 | 850ms | 888ms | 1025ms | 1089ms |
| 生成（prompt + LLM） | 0（未测，见上方说明） | - | - | - | - |
| 端到端（检索+重排，不含生成） | 24 | 1011ms | 1000ms | 1475ms | 1811ms |

**串行单用户 QPS ≈ 0.99**（不含生成段；未做并发，多用户场景要另测，主要瓶颈在 LLM 生成段的排队）。

复现：`.venv\Scripts\python.exe scripts\benchmark.py`（需 VM 开机、.env 有效；LLM 不可达时加 `--skip-llm`）。
