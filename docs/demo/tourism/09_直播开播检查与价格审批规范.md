# 直播开播检查与价格审批规范

## 开播前检查

运营须在开播前完成选品、库存、活动时间、计划到手价、商品说明和宣传依据检查。存在库存不足、计划价不一致或缺少商品说明等阻断项时，场次不得发布。

## 价格修改审批

RPA 发现平台直播价与计划价不一致时，只能生成修改申请，不能直接写入平台。申请中必须记录 SKU、修改前价格、目标价格、触发巡检结果和业务原因。

执行人和审批人必须分离，申请人不得审批自己的申请。场次负责人或管理员批准后，系统才生成一次性执行任务；执行前再次读取当前价格，执行后重新读取并验证目标值。重复点击或任务重试不得造成重复改价。

## 留痕要求

采集、登录、修改、验证各步骤须记录状态、耗时和失败原因。高风险写操作保留审批人、批准时间、预期值和执行结果，用于审计与单场复盘。
