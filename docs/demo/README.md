# 演示文档与真机验证清单

三份制度文档，**分属三个互不重叠的业务域**。同质文档测不出检索质量（3 个 chunk 时
16/16 全对是假绿，P13 的 query 改写实验踩过这个坑），所以刻意让它们的数字、流程、
术语都不交叉。

| 文件 | 覆盖 | 独特数字（便于验证"答案确实来自这份文档"） |
|---|---|---|
| 员工考勤与休假管理制度 | 工时、年假、病假、事假、加班调休 | 年假 5/10/15 天按工龄分档、病假工资 60%~100% 五档 |
| 费用报销管理制度 | 差旅、住宿、招待、审批权限、时限 | 住宿 900/650/500 元三档、审批 2000/10000/50000 三档、30 天报销时限 |
| IT设备与信息安全规范 | 设备申领、密码策略、数据外发、离职 | 密码 12 位/90 天、笔记本 4 年更换、锁定 30 分钟 |

**三份都故意没写**：食堂与班车、薪酬结构、绩效考核细则、组织架构。
→ 用来测「库里没有」那条路径（`no_evidence`）。

## 上传

优先 `.md`（最快，不依赖 PDF 解析）。建一个知识库（如"公司制度"），三份一起传，
盯后端日志：解析 → 切块 → 调 BGE-M3 → 写 Milvus。等状态变 `completed`。

## 照着问（每行 = 一次问答，括号里是预期）

**A 组 · 简单事实（应命中单份文档）**
1. 年假有几天？（5/10/15 按工龄，来自考勤制度）
2. 出差住宿能报多少？（三档城市标准，来自报销制度）
3. 密码多久换一次？（90 天，来自 IT 规范）

**B 组 · 需综合同份文档的多段**
4. 报销 3 万块要哪些人审批？（10000~50000 档：部门负责人→财务总监→分管副总裁）
5. 入职第一年年假怎么算？（折算公式 + 满 3 个月次月可用）

**C 组 · 库里没有（应 `no_evidence`，且不调模型）**
6. 公司食堂开放时间是什么时候？
7. 绩效考核分几个等级？

**D 组 · 多轮追问（验会话历史）**
8. 先问"年假有几天" → 再问"那入职半年呢？"（第二轮依赖同一份文档的折算段）

## 每轮都要看的四件事

1. 答案里的 `[1]` 与下方引用列表的编号一一对应；
2. **答案下方有 `tokens: N`** —— 这是 `stream_usage` 的唯一真实验证点（纯 RAG 走流式）；
3. 字是逐字蹦出来的，不是整段出现；
4. Agent 模式重问一次，看执行轨迹 4 步与节点级进度。

> C 组若返回了"根据公司规定…"式的编造内容，那是真问题；若返回"未检索到相关资料"，
> 说明守卫生效。把两者结果都记下来。
