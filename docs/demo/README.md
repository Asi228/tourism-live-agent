# 旅游直播电商项目演示指南

## 1. 初始化完整演示数据

确保 MySQL、Redis、Milvus 和项目配置可用，然后执行：

```powershell
.venv\Scripts\python.exe scripts\seed_tourism_demo.py --reset --remove-legacy
.venv\Scripts\python.exe scripts\check_runtime.py --strict
```

脚本创建以下可复现内容：

- 访客账号：`demo_operator / Demo@123456`；
- 3 个公开知识库、10 份旅游业务文档及 Milvus 向量；
- 6 个旅游商品、8 个 SKU、库存快照与直播活动；
- 可开播、待处理、已结束三种直播场次；
- 一条待审批改价申请、一条已执行审批和两类 RPA 历史任务。

`--reset` 只重建固定名称的旅游演示数据；`--remove-legacy` 额外删除早期洗护商品演示数据。

## 2. 推荐展示路线

1. 从“项目介绍”说明业务背景、系统边界和技术架构。
2. 在登录页点击“访客演示账号 / 一键填入”，登录普通运营账号。
3. 打开“运营工作台”，查看直播场次、待处理风险、审批和自动化指标。
4. 打开“直播任务”：
   - “周末亲子景区门票专场”已经通过价格、库存和资料检查；
   - “三亚酒店套餐特惠专场”因可售房量不足、计划价不一致而被阻断；
   - “城市周边游回顾专场”用于展示场次复盘。
5. 在“运营 Agent”询问“酒店场次为什么不能开播”，展示结构化风险解释和处理顺序。
6. 在“风险与审批”查看 1999 元改价申请，说明申请人不能自批和一次审批一次执行。
7. 在“自动化任务”查看登录、采集、落库、巡检步骤与前后值验证。
8. 在“知识问答”选择相应知识库，展示引用来源与多轮追问。

## 3. 建议知识问答

| 问题 | 预期依据 |
|---|---|
| 欢乐谷成人票最晚什么时候免费退？ | 出游日前一天 18:00 前 |
| 三亚酒店周六入住需要补多少钱？ | 每间夜加价 300 元 |
| 酒店套餐预约成功后还能改期吗？ | 入住日前 3 天 18:00 前可免费改期一次 |
| 景区临时闭园订单怎么处理？ | 未核销订单按官方通知全额退款 |
| RPA 发现直播价不一致能直接改吗？ | 不能，须生成申请并由负责人或管理员审批 |
| 申请人能审批自己的改价申请吗？ | 不能，执行人和审批人必须分离 |

每轮检查答案引用编号、引用原文、检索路径和会话连续性。再询问“公司班车几点发车”，系统应返回
未检索到依据，而不是编造答案。

## 4. 真实 RPA 演示

先运行完整项目栈，再在另一终端执行：

```powershell
.venv\Scripts\python.exe scripts\start_stack.py
.venv\Scripts\python.exe scripts\demo_live_rpa.py
```

脚本通过 Redis → Playwright Worker → 模拟平台 → MySQL 快照 → 自动巡检完成真实链路。预置异常为
计划销量 30、可售房量 8，计划价 1999 元、平台直播价 2199 元。真实平台接口需要平台授权和
稳定测试账号，因此作品展示使用功能等价的模拟后台验证自动化能力。

## 5. 故障恢复

```powershell
.venv\Scripts\python.exe scripts\recover_rpa_tasks.py
.venv\Scripts\python.exe scripts\recover_rpa_tasks.py --apply
```

第一条只预览；第二条只恢复可安全重试的只读采集任务和入队失败任务。高风险改价、下架失败后
保留人工核验，不会自动重复执行。
